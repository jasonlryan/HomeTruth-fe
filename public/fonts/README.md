# HomeTruth Font Assets

These WOFF2 files provide the HomeTruth brand font for browser rendering:

- `gill-sans-light.woff2` — Gill Sans Light, weight 300
- `gill-sans-regular.woff2` — Gill Sans Regular, weight 400
- `gill-sans-bold.woff2` — Gill Sans Bold, weight 700

They were generated from the local macOS Gill Sans collection at
`/System/Library/Fonts/Supplemental/GillSans.ttc`.

Confirm web embedding rights for production distribution before sharing these
assets outside the authorised project repositories.
