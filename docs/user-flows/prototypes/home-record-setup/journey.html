Flow and data notes

  1. Ask as a guest. The route changes the sample question. The guest conversation carries the question and reply. A property address is optional at this point.
  2. Choose to save a record. Login resumes the journey for an existing user. Account creation adds the welcome step before property setup. The prototype simulates these steps with a demo account.
  3. Start or return to a home record. A new record requires an address and a confirmed relationship. An existing record opens directly. Both paths keep the original answer available when it was recovered.
  4. Save or continue the question. Saving keeps the address and relationship together. Reopening the question takes you back to the same conversation. You can do this before or after saving.
